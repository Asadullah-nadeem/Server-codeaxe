API Documentation

Welcome to the CodeAxe backend API documentation. This API powers both the public website frontend and the secure admin dashboard.

Base URL

https://api.codeaxe.co.in/api

Required Headers

Header Requirement Description
Accept Required Must be application/json
X-App-Key Required* The NEXT_PUBLIC_APP_KEY from env. Required for public site routes.
Authorization Auth Only Bearer {token}. Required for protected routes.

Authentication

Most endpoints are protected by Middleware. There are three types of authentication:

  • App Key: For public data fetching (CMS content).
  • User Token: For registered client accounts.
  • Admin Token: For staff/superadmin access to the dashboard.

Public Content API

Use these routes to fetch content for the frontend website.

GET /nav
Fetches navigation links and global site settings (logo, name, etc).
Headers X-App-Key: {APP_KEY}
GET /home
Fetches all sections for the homepage (Hero, Services, Stats, etc).
Headers X-App-Key: {APP_KEY}
POST /contact/submit
Submits a new contact form message.
{

User Authentication

POST /auth/login
Logs in a frontend user. Returns an access token.
GET /dashboard
🔒 Requires User Authorization Header
Fetches the user's project board and history.

Admin Management API

Full control over the CMS and system settings. Requires Admin Token.

GET /admin/chat/overview
🔒 Requires Admin Auth Middleware
Fetches all active conversations between admins and clients.
PUT /admin/nav/settings
Updates global site branding (Title, Logo, Prefix).
GET /admin/list
Superadmin Only
Returns a list of all administrator accounts.

DMS (Media Management)

Handles cloud image hosting and serves them via a secure proxy.

GET /dms/media/{slug}/{id}
Serves an image. This route is public and provides optimized media delivery.
POST /dms/media
🔒 Requires DMS API Key (Upload Scope)
Uploads a new media asset to the cloud provider.
